# Supremo Concursos (MVP funcional)

Aplicativo web full-stack em português (Brasil) para organizar estudo de concursos a partir de edital.

## Execução
```bash
python app.py
```
Acesse `http://127.0.0.1:5000`.

## Entregue nesta versão
- Autenticação com sessão e persistência em SQLite.
- Upload/colagem de edital com revisão manual do texto extraído.
- Verticalização automática (Disciplina > Tópico > Subassunto) com edição de status.
- Plano semanal, metas, sessões de estudo e simulados.
- Analytics com perfil, recomendações e scores de domínio/risco/prioridade.
- Dados demo para acelerar validação de conceito.
